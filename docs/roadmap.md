# CloudIt Future Engineering Roadmap

CloudIt already implements the core infrastructure, CI/CD, containerization, Kubernetes, persistence, monitoring, and AWS deployment capabilities originally planned for the project.

Future improvements include:

- Amazon EKS
- Application Load Balancer
- Custom domain and HTTPS
- Private application subnets
- AWS Secrets Manager or SSM Parameter Store
- Amazon CloudWatch
- Amazon RDS
- Automated backups and recovery
- Multi-AZ architecture
- Additional failure-recovery testing
- Further IAM least-privilege hardening

See the root `README.md` for current project capabilities.
